# My Website

A personal portfolio website showcasing my projects, personal interests, and contact information.

## Structure

The website is now a single-page application with three main sections:

1. **Projects Section** - The main landing area featuring a grid of my projects with filtering capabilities
2. **Personal Section** - Interactive map and bucket list showcasing my interests and travels
3. **Contact Section** - Contact information and links to my professional profiles

## Features

- **Single Page Design**: All content is on one page with smooth scrolling between sections
- **Project Showcase**: Interactive project grid with hardware/software filtering
- **Project Details**: Detailed project views with rich content blocks (text, images, grids, quotes, etc.)
- **Responsive Design**: Works on desktop and mobile devices
- **Smooth Navigation**: Sticky navbar with smooth scrolling to sections
- **Modern UI**: Clean, professional design with subtle animations

## Navigation

- **Projects**: Jump to the projects section
- **Personal**: Jump to the personal section with map and bucket list
- **Contact**: Jump to the contact section

## Development

```bash
npm install
npm run dev
npm run build
```

## Technologies

- React + TypeScript
- Vite for build tooling
- CSS-in-JS for styling
- React Router for project detail navigation
